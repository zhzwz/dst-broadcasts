# Broadcasts

《饥荒联机版》纯服务端播报模组。客户端无需订阅，也不会向存档写入额外数据。

> “全服”指当前分片的全部玩家；地面与洞穴会分别播报各自发生的事件。

## 功能

### 袭击倒计时

- 预警猎犬、洞穴蠕虫、巨鹿与熊獾袭击
- 提前 1 个游戏日提醒
- 在来袭前 5 分钟、2 分钟、1 分钟、30 秒、10 秒与 5 秒再次提醒
- 袭击开始时立即播报

> [Broadcasts] 距离猎犬来袭还有5秒，请做好准备！

### 物品状态提醒

- 可缝补物品：耐久降至 20%、10%、5%、4%、3%、2% 或 1% 时提醒
- 可补充燃料物品：燃料降至 30%、20% 或 10% 时提醒
- 玩家持有的武器、护甲或其他物品损毁时提醒

> [Broadcasts] 某玩家的某物品耐久仅剩10%，请及时缝补！

### 巨兽动态

- 每个游戏日开始时，汇总当前分片仍然存活的巨兽
- 巨鹿、熊獾及其变异形态现身时立即播报
- 巨兽被击败时立即播报
- 支持龙蝇、蜂王、帝王蟹、天体英雄、天体后裔等主要巨兽

> [Broadcasts] 第 31 天巨兽简报：龙蝇、蜂王仍然存活。

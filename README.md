# DST Broadcasts

饥荒联机版全服播报模组。纯服务端模组，客户端无需安装。不写入任何数据到存档。

## 功能

### 袭击预警

- 猎犬 / 洞穴蠕虫等追猎类型的袭击
- 巨鹿 / 熊獾等会主动寻找玩家的袭击
- 游戏时间，提前 1 天提醒
- 现实时间，提前 5 分钟、2 分钟、1 分钟、30 秒、10 秒、5 秒提醒

> [Broadcasts] {猎犬}还有五秒到达战场，请做好准备！


### 可缝补物品低耐久提醒

- 阈值：20% / 10% / 5% / 4% / 3% / 2% / 1%

> [Broadcasts] {某玩家}的{某物品}剩余{10%}耐久，请及时缝补！

### 可补充燃料物品低耐久提醒

- 阈值：30% / 20% / 10% 

> [Broadcasts] {某玩家}的{某物品}剩余{10%}燃料，请及时补充！


### 物品损坏提醒

- 武器、护甲、物品等损坏时

> [Broadcasts] {某玩家}的{某物品}已损毁！


### 巨兽存活播报

- 龙蝇、蜂王、蟾蜍、帝王蟹、天体英雄等，每天刷新时若已在世界中则提示
